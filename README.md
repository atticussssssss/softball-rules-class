# 慢投垒球规则课

给零基础新队员上的一节慢投垒球规则课。全部是单个 HTML 文件，双击就能用，
不需要装任何东西，不联网也正常。规则按本队所在联赛的规程写，不是通用规则。

## 上课用

**[放映台.html](放映台.html)** —— 上课只开这一个。

左侧目录八个板块，点一下跳一页，页面不滚动，一页就是一屏。
每页的「▶ 播放」点一下播一段动画，播完停住，再点播下一段 —— 动画不会自己走，
节奏由讲课的人控制。「讲解提示」按钮打开后，每一步下面会出现橘色提示，
写着这一步讲几分钟、强调什么，投影时可以关掉。

第五页「情景」有**考验模式**：点垒包设跑垒员、设出局数、设击球方向，
让队员先猜判断结果，再看动画跑一遍。

八个板块：

| | 板块 | 讲什么 |
|---|---|---|
| 1 | 开场 | 一场比赛怎么进行，四种出局 |
| 2 | 双方基础 | 被迫进垒、封杀与触杀、飞球补踩 |
| 3 | 打者眼中的球场 | 站在本垒看全场，十个守备位置、打击空当、跑垒路线 |
| 4 | 打席 | 从投球到结果，合法弧线、好球垫、球数 |
| 5 | 情景 | 十三个情景，每个分守备方和跑垒员两种视角 |
| 6 | 单方面补充 | 守备独有、跑者独有 |
| 7 | 场上场下 | 裁判手势、死球、联赛规则 |
| 8 | 收尾 | 下场前三件事 |

## 课后发给队员

- **[速查卡.html](课后发给队员/速查卡.html)** —— 一页纸，点「打印」可直接打印或存 PDF
- **[慢投垒球规则课.html](课后发给队员/慢投垒球规则课.html)** —— 自学版，可滚动细读

## 目录

```
放映台.html            上课用，由 单页/ 里八页合并生成
使用说明.txt           给 Windows 电脑用的说明（UTF-8 BOM + CRLF，记事本可读）
规则课大纲.md          课程设计文档，改动都先记在这里
打包.py                生成 慢投垒球规则课.zip
课后发给队员/          速查卡、自学版
单页/                  八页原件 + build_console.py
存档/                  已作废的十五页幻灯片版，留着不用
```

改了 `单页/` 里任何一页之后，要重新生成放映台：

```bash
cd 单页 && python3 build_console.py
```

打包成压缩包拷到 U 盘或发微信：

```bash
python3 打包.py
```

## 环境

在 Windows 上验证过：全部 UTF-8 无 BOM、首行有 charset 声明，本地双击不乱码；
除 Google 字体外零外部依赖，断网可用；字体栈含微软雅黑，没网时不缺字；
1366x768 不裁切。用 Chrome 或 Edge 打开，Windows 自带的 Edge 就行。

不要用记事本编辑 HTML，会破坏编码。
