慢投垒球规则课 · 使用说明

【一、上课用什么】
   放映台.html   —— 上课就打开这一个文件。
   左侧是目录，八个板块，点一下跳一页。
   每页右下角的「▶ 播放」按钮：点一下播一段动画，播完停住，再点播下一段。
   动画不会自己走，节奏完全由你控制。
   「讲解提示」按钮：打开后每一步下面会出现橘色的提示文字，只有你看得见，
   写着这一步讲几分钟、强调什么。
   第五页「情景」右上角有「考验模式」：可以自己点垒包设人、设出局数、
   设击球方向，让队员先猜再看结果。

【二、怎么打开】
   双击 放映台.html 即可，用 Chrome 或 Edge 打开。
   Windows 自带的 Edge 就可以，不需要装任何东西，也不需要联网。
   如果双击后是用别的程序打开的：右键 → 打开方式 → 选择 Microsoft Edge。
   打开后按 F11 全屏，投影效果最好。
   笔记本 1366x768 及以上的分辨率都正常显示。

【三、联网与字体】
   文件里用的中文字体，联网时会自动下载更好看的字体；
   不联网也完全正常，会自动换成 Windows 自带的微软雅黑，只是字形略有不同。
   教室没网不影响上课。

【四、课后发给队员】
   课后发给队员 文件夹里两个文件：
   速查卡.html          —— 一页纸速查，打开后点右上角「打印」可以直接打印
                           或存成 PDF，发群里也行。
   慢投垒球规则课.html  —— 自学版，可以上下滚动细读，内容按我们联赛规则写的。

【五、单页 文件夹】
   放映台里那八页的单独文件，改动或单独讲某一页的时候用。
   如果改了单页里的文件，需要重新生成放映台：
   进入 单页 文件夹执行 python3 build_console.py
   平时上课用不到这个文件夹。

【六、注意】
   所有文件都是单个 HTML，互相不依赖，可以随便复制、拷到 U 盘、发微信。
   不要用记事本打开 HTML 文件编辑，会破坏编码。
